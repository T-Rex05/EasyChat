# 网络调研

系统化的网络研究方法论 — 搜索信息、筛选可信来源、提取关键内容、综合成结构化报告。

## 何时使用

- 用户问 "调研XX技术"
- 需要对比多个方案
- 需要最新的行业信息
- 需要验证某个技术问题

## 调研流程

### 1. 规划搜索
- 将调研主题拆解为 3-5 个搜索子问题
- 确定关键搜索词（中英文）
- 明确需要的信息类型（教程、对比、基准测试、官方文档等）

### 2. 搜索与筛选
- 对每个子问题进行网页搜索
- 优先选择：官方文档 > 权威技术博客 > Stack Overflow > 个人博客
- 排除：付费内容、404页面、过时信息（>2年）

### 3. 提取关键信息
- 阅读页面内容，提取相关段落
- 记录：来源URL、关键数据、核心观点
- 标注信息可信度（官方/社区/个人）

### 4. 综合报告
按以下结构输出：
```
## 调研报告: [主题]

### 概述
一段话总结核心发现

### 方案对比
| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|

### 关键发现
- 发现1（来源：URL）
- 发现2（来源：URL）

### 建议
基于调研结果的推荐方案
```

## 注意事项

- 不要直接复制大段原文，要进行综合提炼
- 标注信息来源，便于用户查证
- 如果搜索结果质量差，向用户说明局限性
- 避免依赖单一来源，交叉验证关键信息
