# /travel-planner — 旅游路线规划

根据用户需求规划旅游行程，搜索目的地信息并生成结构化日程。

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 目的地 | ✅ | 城市/地区名 |
| 天数 | ✅ | 游玩天数 |
| 预算 | ❌ | 总预算（元），默认不限制 |
| 偏好 | ❌ | 美食/自然/人文/购物/亲子/休闲，默认综合 |

## 流程

### 1. 收集需求

缺失必填字段时主动询问，偏好和预算缺失则使用默认值。

### 2. 搜索信息

使用 `web_search` 搜索以下内容（并行搜索）：

- 「{目的地} 必去景点 top10」
- 「{目的地} {天数}天 旅游攻略」
- 「{目的地} 特色美食 推荐」
- 「{目的地} 住宿 推荐区域」（如预算有限则加「平价」）
- 「{目的地} 天气」（3 天以上行程时搜索）

### 3. 生成行程

按以下规则编排：

- **就近原则**：同一天景点地理上邻近，减少路途耗时
- **节奏合理**：上午 1-2 个景点 → 午餐 → 下午 1-2 个景点 → 晚餐 → 晚间活动（可选）
- **日均费用**：预算 / 天数，分配比例为 住宿 40% + 餐饮 30% + 门票交通 30%

### 4. 输出格式

```markdown
## 🗺️ {目的地} {天数}日游行程

**预算**：{预算或"无限制"} | **偏好**：{偏好标签}

### Day 1：{主题}
| 时间 | 项目 | 地点 | 费用 |
|---|---|---|---|
| 09:00 | ... | ... | ¥... |

...（每天一张表）

### 💰 费用汇总
| 类别 | 预估费用 |
|---|---|
| 住宿 | ¥... |
| 餐饮 | ¥... |
| 门票+交通 | ¥... |
| **合计** | **¥...** |

### 📝 小贴士
- 基于搜索结果的实用提示（天气穿衣、交通方式、预订建议等）
```

## 注意事项

- 景点门票价格如有搜索结果则引用，否则标注"以实际为准"
- 输出中标注信息来源（搜索结果的 URL）
- 遇到搜索结果不足时，诚实说明并给出已有信息
