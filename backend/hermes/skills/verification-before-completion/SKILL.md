# 完成前验证

**核心原则：声称之前必有证据。**

## 门禁函数

```
声明任何状态或表示满意之前：

1. 识别：什么命令能证明这个声明？
2. 运行：完整执行（新鲜、一次跑完）
3. 读取：完整输出、退出码、失败数
4. 验证：输出确认了声明吗？
   - 否 → 陈述实际状态并附证据
   - 是 → 陈述声明并附证据
5. 然后才：做出声明

跳过任何一步 = 撒谎
```

## 常见对应

| 声明 | 需要 | 不够 |
|---|---|---|
| 测试通过 | 测试命令输出：0 失败 | 上次跑的、"应该没问题" |
| 构建成功 | 构建命令：exit 0 | Lint 过、日志看着好 |
| Bug 修复 | 验证原症状消失 | 代码改了、假设好了 |

## 红牌

用"应该""大概""好像" → 停。满意声明前没跑验证 → 停。准备 commit 前没验证 → 停。
