# /test-report — 测试报告生成

生成一份简单的测试报告。结构清晰，内容简洁。

## 工作流

### 1. 收集信息
向用户确认：
- 报告主题
- 报告范围（时间、项目等）

### 2. 生成报告
按以下模板输出报告：

```
# {主题} 报告

## 概述
简要说明报告背景和目的。

## 主要内容
- 关键发现 1
- 关键发现 2
- 关键发现 3

## 结论
一句话总结。

## 建议
1. 建议项 1
2. 建议项 2
```

### 3. 交付
将报告内容展示给用户，确认是否满意。
