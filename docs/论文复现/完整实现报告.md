## 🚀 使用方式

### 方式一：通过 Web UI（推荐）

1. 启动 AgentForge：
   ```bash

   ```

2. 访问前端：`http://localhost:8001`

3. 点击侧边栏「论文复现」菜单

1. 在聊天界面输入：
   ```

   ```

2. Hermes 自动调用 `paper-reproduction` 技能

3. 跟随助手完成复现流程

### 方式三：直接调用工具

```python
from backend.tools.paper_reproduction import (
    parse_paper,
    extract_claim_rubric,
    discover_repo
)

# 解析论文
parsed = parse_paper.invoke({"paper_url": "https://arxiv.org/abs/1706.03762"})

# 提取主张
rubric = extract_claim_rubric.invoke({"parsed_paper": json.loads(parsed)})

# 发现仓库
repos = discover_repo.invoke({
    "parsed_paper": json.loads(parsed),
    "claim_rubric": json.loads(rubric)
})
```

## 🎓 核心概念

### 四层证据验证

```
Layer 1: Claim (主张)
   ↓
Layer 2: Criterion (准则)
   ↓
Layer 3: Evidence (证据)
   ↓
Layer 4: Judgment (判定)
```

**判定逻辑**：
- 量化主张：自动比较期望值与实际值
- 定性主张：标记为人工审查
- 置信度计算：`verified / total`

### Rubric 冻结机制

```python
# SHA-256 哈希确保验收标准不可篡改
rubric["sha256"] = hashlib.sha256(
    json.dumps(rubric, sort_keys=True).encode("utf-8")
).hexdigest()
```

### Docker 沙箱设计

```
四操作设计：
- create: 创建容器
- execute: 执行命令
- destroy: 销毁容器
- status: 查看状态

安全机制：
- 自动回滚（max_patches=3）
- 超时控制
- 隔离环境
```
