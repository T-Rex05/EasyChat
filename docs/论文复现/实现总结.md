## 技术亮点

### 1. Rubric 冻结机制

```python
# SHA-256 哈希确保验收标准不可篡改
rubric_json = json.dumps(rubric, sort_keys=True, ensure_ascii=False)
rubric["sha256"] = hashlib.sha256(rubric_json.encode("utf-8")).hexdigest()
```

### 2. 四层证据验证

```
Layer 1: Claim (主张) - 论文中的核心观点
Layer 2: Criterion (准则) - 可量化的验收标准
Layer 3: Evidence (证据) - 代码运行结果
Layer 4: Judgment (判定) - 自动或人工判定
```

### 3. Docker 沙箱隔离

```python
# 四操作设计
actions: create / execute / destroy / status

# 自动回滚机制
max_patches = 3  # 最多 3 次修复尝试
```

### 4. LLM 驱动调试

```python
# 使用 LLM 分析错误并生成补丁
def _llm_generate_patch(error_msg: str) -> Optional[Dict]:
    model = _get_llm()
    response = model.invoke(f"分析错误并生成修复补丁: {error_msg}")
    return json.loads(response.content).get("patch")
```

## 使用方式

### 方式一：通过 Skill 文件（推荐）

1. 启动 AgentForge 服务：
   ```bash
   python main.py
   ```

2. 在对话中使用：
   ```
   用户: 帮我复现这篇论文 https://arxiv.org/abs/1706.03762
   ```

3. Hermes 会自动调用 `paper-reproduction` 技能，按流程执行

### 方式二：直接调用工具

```python
# 解析论文
parsed_paper = parse_paper.invoke({
    "paper_url": "https://arxiv.org/abs/1706.03762"
})

# 提取主张
rubric = extract_claim_rubric.invoke({
    "parsed_paper": json.loads(parsed_paper),
    "max_claims": 5
})

# 发现仓库
repos = discover_repo.invoke({
    "parsed_paper": json.loads(parsed_paper),
    "claim_rubric": json.loads(rubric)
})

# 调试代码
setup_result = debug_paper_code.invoke({
    "action": "setup",
    "repo_url": json.loads(repos)["repos"][0]["html_url"]
})

# 构建证据图谱
graph = build_evidence_graph.invoke({
    "rubric": json.loads(rubric),
    "execution_results": {...}
})
```
