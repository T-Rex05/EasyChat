## 端到端流程

### 第一步：环境准备

```bash
# 克隆项目
git clone https://github.com/yu-xin-c/Sea-mult-agent.git
cd Sea-mult-agent/scholar-agent

# 配置环境变量
cp backend.env.example backend.env
# 编辑 backend.env，填写：
# - OPENAI_API_KEY
# - OPENAI_BASE_URL
# - OPENAI_MODEL_NAME
```

### 第二步：启动服务

```bash
# 终端 1：启动沙箱
make run-sandbox

# 终端 2：启动后端
make run-backend

# 终端 3：启动前端
make run-frontend
```

### 第三步：验证健康

```bash
# 检查后端
curl http://localhost:8080/api/health

# 检查沙箱
curl http://localhost:8082/api/v1/sandboxes
```

## API 示例

### 1. 创建计划

**请求**：

```bash
curl -X POST http://localhost:8080/api/plan \
  -H 'Content-Type: application/json' \
  -H 'X-User-Id: demo-user' \
  -d '{
    "intent": "复现 Attention Is All You Need，使用 https://github.com/harvardnlp/annotated-transformer，smoke 模式"
  }'
```

**响应**：

```json
{
  "id": "plan-2026-07-17-001",
  "intent": "复现 Attention Is All You Need...",
  "intent_context": {
    "intent_type": "Paper_Reproduction",
    "paper_url": null,
    "repo_url": "https://github.com/harvardnlp/annotated-transformer",
    "mode": "smoke"
  },
  "status": "pending",
  "nodes": [
    {
      "id": "paper_parse",
      "type": "paper_parse",
      "assigned_to": "librarian",
      "status": "pending"

    {
      "id": "claim_rubric_extract",
      "type": "claim_rubric_extract",
      "assigned_to": "librarian",
      "dependencies": ["paper_parse"],
      "status": "pending"
    }
    // ... 其他节点
```

### 2. 执行计划

**请求**：

```bash
curl -X POST http://localhost:8080/api/plans/plan-2026-07-17-001/execute \
  -H 'X-User-Id: demo-user'
```

**响应**：

```json
{
  "status": "running",
  "message": "Plan execution started"
}
```

### 3. 订阅 SSE 事件

**请求**：

```bash
curl -N http://localhost:8080/api/plans/plan-2026-07-17-001/stream \
  -H 'X-User-Id: demo-user'
```

**事件流**：

```

event: artifact_created
data: {"task_id":"paper_parse","artifact_name":"parsed_paper","timestamp":"2026-07-17T00:00:10Z"}

event: task_completed
data: {"task_id":"paper_parse","timestamp":"2026-07-17T00:00:11Z"}
```

## 前端操作

### 1. 访问 Web UI

打开浏览器，访问：http://localhost:5173

### 2. 输入指令

在聊天输入框输入：

```text
请使用 https://github.com/harvardnlp/annotated-transformer 复现
Attention Is All You Need，使用 smoke 模式运行轻量注意力消融。
```

### 3. 查看 DAG

系统会生成并显示 DAG：

```
解析论文 -> 冻结主张 Rubric
    \-> 检索仓库 -> 准备工作区 -> 解析依赖
        -> 准备运行时 -> 安装依赖 -> 执行实验 -> 对比论文声明
                                                  -> 主张证据图
```

### 4. 观察执行

- 点击节点查看实时日志
- 查看生成的代码、报告、指标
- 查看证据图谱

## 常见问题

### Q1: Docker Sandbox 连接失败？

**检查清单**：
1. Docker Desktop 是否启动？
2. `SANDBOX_URL` 是否正确？
3. 端口 8082 是否被占用？

**解决方法**：

```bash
# 检查 Docker
docker ps

# 检查端口
lsof -i :8082

# 重启沙箱
make run-sandbox
```

### Q2: 论文复现一直失败？

**可能原因**：
1. 模型 API Key 无效
2. 仓库不存在或权限问题
3. 依赖安装失败

**调试方法**：

```bash
# 查看任务日志
curl http://localhost:8080/api/plans/:id/events \
  -H 'X-User-Id: user-id'

# 查看后端日志
tail -f logs/backend.log
```

### Q3: 前端 SSE 断线？

**原因**：
- 后端重启后需要重新订阅
- CORS 配置问题

**解决方法**：

```bash
# 检查 CORS 配置
grep CORS_ALLOWED_ORIGINS backend.env

# 重启前端
make run-frontend
```

### Q4: Benchmark 指标不一致？

**可能原因**：
1. 数据预处理不一致
2. 评测口径不一致
3. 随机种子未固定

**调试方法**：

```bash
# 查看校验报告
curl http://localhost:8080/api/plans/:id/artifacts/benchmark_validation_report

# 查看逐样本预测
curl http://localhost:8080/api/plans/:id/artifacts/benchmark_predictions_path
```

## 性能优化

### 1. 并行化

Scheduler 默认并发数为 2，可以通过配置调整：

```bash
# backend.env
SCHEDULER_MAX_CONCURRENT=4
```

### 2. 缓存

- 计划和 Artifact 保存在 `PLAN_STORE_PATH`
- 事件历史支持回放，减少重复请求

### 3. 资源限制

Docker 容器默认资源限制：

```bash
# backend.env
SANDBOX_DOCKER_CPU=2
SANDBOX_DOCKER_MEMORY=4g
SANDBOX_DOCKER_PID=256
```
