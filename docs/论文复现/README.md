## 💡 关键设计理念

### 1. 自动化必须有边界

```
┌──────────────────────────────────────────────────────────┐
│              边界控制三原则                                │
├──────────────────────────────────────────────────────────┤
│  ✓ 重试有上限     │ 依赖安装 3 次、代码调试 2 轮          │
│  ✓ 并发有上限     │ Scheduler 最大并发 2                   │
│  ✓ 预算有上限     │ 任务尝试 100 次、总时长 2100 秒       │
│  ✓ 修改有范围     │ 只修改已存在的 Python 文件             │
│  ✓ 证据有校验     │ Go harness 重算指标，模型不能自证成功  │
└──────────────────────────────────────────────────────────┘
```

### 2. 模型负责建议，代码负责约束

| 职责 | 模型 (LLM) | 代码 (Go) |
|------|-----------|----------|
| **决策** | 提出补丁方案、生成适配器 | 校验路径、策略、哈希 |
| **执行** | - | 写入文件、创建容器 |
| **验证** | - | 重算指标、检查指纹 |
| **判定** | 判断证据状态 | 引用检查、状态白名单 |

### 3. Artifact 驱动协作

```
Agent A                  Agent B                  Agent C
   │                        │                        │
   ├─→ Artifact 1 ──────────┤                        │
   │                        ├─→ Artifact 2 ──────────┤
   │                        │                        └─→ Artifact 3
   │                        │
   └─→ 不共享内存，通过显式命名产物协作
```
