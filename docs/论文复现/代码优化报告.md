### 3. ✅ 完善错误处理和重试机制

**重试装饰器**：
```python
@retry_on_failure(
    max_retries=3,
    delay=1.0,
    backoff=2.0,
    exceptions=(ConnectionError, TimeoutError)
)
def _download_paper(url: str) -> Path:
    # 下载逻辑
    pass
```

**重试 Session**：
```python
session = create_retry_session(
    total_retries=3,
    backoff_factor=1.0,
    status_forcelist=(429, 500, 502, 503, 504)
)
response = session.get(url, timeout=60)
```

**优化效果**：
- ✅ 网络请求自动重试
