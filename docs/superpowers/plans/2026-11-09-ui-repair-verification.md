# 界面与功能回归修复记录

日期为 2026-11-09。以当前工作区为基线，保留既有未提交修改。

## 已修复

1. 聊天导航栏和历史栏增加拖动分隔条，支持鼠标、指针、方向键、Home/End 和双击复位。统一清理监听器，拖动过程中暂停选择文字，结束、失焦或组件卸载时恢复。两栏分别有宽度上下限。
2. 超级代理表单与任务卡片补内边距，收敛表单间隔，输入框不超出卡片，操作按钮保持单行，窄屏表单调整排列。
3. 权限接口的平铺定义归一为分组，兼容旧分组响应，修复角色弹窗渲染异常。角色卡片支持键盘，超级管理员列表显示全部权限。工具组补 description/desc 和默认分组映射，消除 undefined 标题。
4. 记忆新增使用受支持的 user_confirmed 来源类型。
5. 技能激活提交当前 active version 作为 CAS 条件，支持连续版本激活，并保留并发冲突提示。
6. 微信手动绑定传 account_id，平台配置保留 base_url。情绪开关统一使用后端布尔值。
7. 模型降级链修复请求字段、响应结构、slots 对象序列化及实际 runtime 后备模型接线。Agent 缓存包含实际模型配置版本与有序后备配置版本，配置变更后同会话重建。
8. 账单上传、登记、解析按真实包装解包。导入统计映射 row_counts 和 quality.commit。图片候选按键值字段编辑，以 extraction_id 确认。退款依据展示实际 match_method/reason，避免 NaN 置信度。
9. 报告下载走带认证的 request client，Blob URL 使用后释放。导航增加已有账单页面入口。
10. 聊天附件上传恢复到统一 files 保存、真实 MIME/大小规则、附件登记、持久引用和归属验证。发送只传 attachment_ids，保留图片预览与粘贴图片上传。
11. 系统配置的服务状态与技能数量接口修正。场景路由呈现服务端明确的能力状态，能力不可用时显示说明，避免继续请求不存在的配置端点。
